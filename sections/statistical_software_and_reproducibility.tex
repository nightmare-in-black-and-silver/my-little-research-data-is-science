\section{Statistical Software and Reproducibility}

\subsection{Statistical Software}

The statistical analysis will be conducted using statistical software supporting data cleaning, variable transformation, descriptive analysis, subgroup and intersectional analysis, and production of tables and figures. Where practical, analysis will be performed programmatically rather than through manual manipulation of the dataset.

\subsection{Analysis Scripts}

Where analysis is conducted programmatically, scripts will be used for data cleaning, recoding, transformation, descriptive analysis, subgroup analysis, and generation of statistical outputs. Scripts will be maintained separately from the raw survey data and organised so that the analytical workflow can be followed from the cleaned dataset through to the reported results.

Analysis scripts will be retained as part of the research materials and, where ethically and practically possible, shared alongside the final publication.

\subsection{Data, Code, and Materials Sharing}

The study will aim to make the analytical code, survey instrument, analysis plan, variable and coding documentation, data-cleaning documentation, and other research materials available to support transparency and reproducibility.

Because the survey may contain sensitive demographic information, public release of respondent-level data will be subject to an assessment of disclosure and re-identification risks. Where appropriate, an appropriately de-identified dataset may be made available.

\subsection{Reproducibility Procedures}

The analysis will be designed to permit the reported descriptive results to be reproduced from the retained analytical data and analysis materials. Data-cleaning decisions, variable coding, derived-variable construction, statistical procedures, and deviations from the preregistered analysis plan will be documented.

Where feasible, the workflow will allow principal tables and figures to be regenerated by rerunning the analysis scripts against the appropriate analytical dataset. Original collected data will be distinguished from cleaned and derived datasets, preserving the transformations applied during analysis.
